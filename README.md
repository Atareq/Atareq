## At ShipBlu

195+ merged pull requests to the core backend (Django REST Framework,
PostgreSQL, Celery, AWS), including:

- **Shopify marketplace:** API client, cart, multi-store checkout and order
  sync connecting merchants' Shopify stores to ShipBlu's fulfillment network.
- **Expiry-aware inventory:** expiry-dated stock batches, storage units that
  hold one SKU and one expiry date, and FEFO (first-expiry, first-out)
  allocation for outbound orders and stock recalls.
- **Merchant payouts and pricing:** automated instant payouts, exchange-order
  pricing and safeguards for orders with missing shipping prices.
- **Customer messaging:** WhatsApp relay with chat history on DynamoDB and
  real-time Firestore notifications for support agents.
- **Delivery operations:** OTP-verified return refunds, the return shipment
  API, structured delivery failure reasons, hourly shipment exports and
  thermal shipping labels.
